# Product Context: Micro-Manager
**Vision** : Une application web simple pour gérer des tâches par colonnes (To Do, Doing, Done).
**Cible** : Utilisateurs solo voulant de la rapidité.
**Features Clés** :
1. Création de colonnes.
2. Ajout de cartes.
3. Drag & drop entre colonnes.
4. Persistance locale (LocalStorage).
